# OligInvest

Prywatna aplikacja webowa (PWA) do analizy inwestycji: portfel, analiza transakcji przeszłych, scenariusze przyszłe, alerty i warstwa edukacyjna. Rynki GPW + USA, waluta bazowa PLN, self-hosting za 0 zł.

**Status:** faza dokumentacji i planowania. Kod aplikacji nie istnieje jeszcze — powstanie w Codex na podstawie `docs/` i `AGENTS.md`.

## Nawigacja

- `docs/00-przeglad/` — wizja, wymagania (FR/NFR), słownik, macierz pokrycia
- `docs/01-architektura/` — C4, stack, moduły, przepływy
- `docs/02-api/` — OpenAPI, SSE, konwencje
- `docs/03-dane/` — źródła danych, model danych, DDL, cache, wzory finansowe
- `docs/04-frontend/`, `docs/05-mobile/` — UI, wydajność, dostępność, PWA/iOS/Android
- `docs/06-bezpieczenstwo/`, `docs/07-wdrozenie/` — STRIDE, ASVS, infra, CI/CD, backup
- `docs/08-plan/` — roadmapa, MVP, backlog, ryzyka, prompty dla Codex
- `docs/09-decyzje/` — ADR-y i audyt pluginów
- `docs/10-ograniczenia.md`, `docs/11-zgodnosc-prawna.md`, `docs/12-dla-uzytkownika/`
